# StockQuantBot Dashboard

AI paper-trading dashboard snapshot.

This repository contains the dashboard code and configuration template only.
Runtime state, SQLite history, backups, and secrets are intentionally excluded.

## Contents

- `dashboard/server.py` - local API/server logic
- `dashboard/static/` - frontend UI
- `.env.example` - environment variable template

## Notes

Copy `.env.example` to `.env` locally and fill in your own API keys before running.
